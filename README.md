# Bitburner Mobile (APK Build)

Неофициальная мобильная сборка (APK) для игры **Bitburner**. 

## 📱 О проекте
Этот репозиторий содержит конфигурацию GitHub Actions и манифест для автоматической сборки Android-приложения (APK) из официальной веб-версии игры с помощью инструмента **Bubblewrap**.

* **Официальный сайт игры:** [bitburner-official.github.io](https://bitburner-official.github.io/)
* **Исходный код игры:** [github.com/bitburner-official/bitburner-src](https://github.com/bitburner-official/bitburner-src)

## 🚀 Как собрать APK
1. Перейдите во вкладку **Actions** в этом репозитории.
2. Выберите workflow **Build Bitburner APK**.
3. Нажмите кнопку **Run workflow**.
4. После завершения сборки, готовый APK-файл можно будет скачать в разделе **Artifacts**.

Этот проект не связан с разработчиками Bitburner. Игра распространяется бесплатно. Данная сборка создана исключительно в ознакомительных целях.# bitburner-apk
